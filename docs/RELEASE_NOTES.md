## RecklessMuse 1.0.0

First release: an 8-voice bitimbral analog-modelled polysynth inspired by the Moog Muse.

**Download `RecklessMuse-macOS.zip`** (universal binary, Apple Silicon + Intel, macOS 11+), unzip, then in Terminal:

```
cd ~/Downloads/RecklessMuse && ./install.sh
```

Contents: VST3, Audio Unit and Standalone app, 267 factory presets.
Builds are not notarised by Apple; the install script removes the download quarantine.

Validated in CI with `auval` (AU) and `pluginval` strictness 5 (VST3).
